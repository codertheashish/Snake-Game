# 🐍 Snake Game

A classic Snake Game built using **Python Turtle Graphics** with speed selection, scoring system, food spawning, and smooth movement.
The game is completely keyboard-controlled and includes multiple speed modes to make gameplay more fun and challenging.

This project includes:

🎮 Arrow Key Controls<br>
⚡ Speed Selection (Slow → Extreme)<br>
🍎 Random Food Shapes & Colors<br>
🏆 Score + High Score System<br>
💥 Border & Self Collision Detection<br>
⏳ Smooth Real-Time Game Loop<br>
⛔ ESC Key → Quit Game Anytime

---

## 🚀 Game Features

### ⚡ Multiple Speed Modes

Choose from **5 speeds** before the game starts:

* Fast
* Normal
* Slow
* Very Fast
* Extreme Mode (Ultra-fast ⚡)

### 🐍 Snake Mechanics

* Smooth head movement
* Growing body segments
* Real-time following motion

### 🍎 Food System

* Random food shape
* Random color
* New food spawns anywhere on the map

### 🧱 Collision Detection

* Border collision → Reset
* Self collision → Reset
* Score resets but **High Score stays**

### ✨ Extra Features

* ESC key → Quit instantly
* Clean UI scoreboard
* Turle graphics animation

---

## 🎮 Controls

| Key           | Action     |
| ------------- | ---------- |
| ⬆ Up Arrow    | Move Up    |
| ⬇ Down Arrow  | Move Down  |
| ⬅ Left Arrow  | Move Left  |
| ➡ Right Arrow | Move Right |
| ESC           | Quit Game  |

## ▶ How It Works (Game Logic)

* Head movement controlled by arrow keys
* Body segments follow previous positions
* Food spawns randomly
* Score increases every time snake eats food
* High score stored until game closed
* Game resets on collision
